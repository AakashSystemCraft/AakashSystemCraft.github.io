        FAQ

        Sawaal jo log pehle poochte hain.

        Aap company ho ya freelancer?

        Main independent freelancer hoon. 2018 se 20+ businesses ke liye systems bana chuka hoon. Aap seedha mujhse baat karte ho, koi middleman nahi, isliye kaam fast hota hai aur cost kam rehti hai.

        Kya mujhe koi software ya server kharidna padega?

        Nahi. System aapke apne Google account (Sheets, Forms, Apps Script) par chalta hai. Koi server, koi monthly fee nahi. Data aapke Drive mein rehta hai.

        Barcode scanner kaunsa chahiye?

        Koi bhi USB ya Bluetooth barcode scanner chalega (₹1,500–2,500 range). Mobile camera se bhi scan ho sakta hai. Barcode labels hum system se hi print karwa dete hain.

        Staff ko computer nahi aata, chalega?

        Haan. Screens simple rakhte hain, bade buttons, Hindi labels agar chahiye. Training hum khud dete hain aur short video bhi banake dete hain.

        Mera purana Excel data kya hoga?

        Purana stock, customer aur product data import kar dete hain, taaki day one se system ready ho.

        Baad mein change chahiye to?

        Support period mein chhote changes free. Naye modules ya bade changes alag quote par, kabhi bhi add ho sakte hain.

        Data safe hai?

        Data aapke Google account mein hai, Google ki security ke saath. Har user ko sirf utna access milta hai jitna uske kaam ke liye chahiye.
